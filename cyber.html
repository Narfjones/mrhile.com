03. Hashing Protocols

Secure

A Hash is a one-way mathematical fingerprint. Secure databases never store actual passwords; they store hashes. Attackers use "Dictionary Attacks" to compare common passwords against stolen hashes.

INPUT SHA-256 HASH

Target: Identify the users with weak passwords by matching their hash fragments.
