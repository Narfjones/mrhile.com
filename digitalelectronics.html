Digital Electronics Curriculum

An interactive guide to the semester.

Semester Timeline

Follow the semester's progression through our interactive timeline. Each unit below outlines the core topics and hands-on activities students will engage in. Click on any unit to expand its details.

Topics:

  • Analog vs. Digital signals
  • Basic electrical concepts (voltage, current, resistance)
  • Introduction to breadboards and basic components
  • Lab Safety Procedures and tool use
  • Understanding circuit diagrams

Activities:

  • Safety quiz and contract
  • Identifying components and using a multimeter
  • Building simple LED circuits on a breadboard

Topics:

  • Binary, Decimal, and Hexadecimal numbers
  • Simple binary addition
  • Basic logic: AND, OR, NOT operations
  • Understanding truth tables

Activities:

  • Converting between number systems
  • Creating truth tables for simple logic
  • Exploring basic Boolean expressions

Topics:

  • Basic logic gates: AND, OR, NOT, XOR, NAND, NOR
  • Using universal gates (NAND and NOR)
  • Identifying Integrated Circuits (ICs)
  • Introduction to circuit simulation tools

Activities:

  • Building and testing basic logic gates on a breadboard
  • Creating simple circuits with logic gates
  • Simulating logic circuits to see how they work

Topics:

  • Designing circuits from truth tables
  • Comparators and Adders

Activities:

  • Designing a circuit for a 7-segment display
  • Building and testing simple adder circuits
  • Creating small combinational circuits for specific tasks

Topics:

  • Safety procedures for soldering
  • Tools for soldering and desoldering
  • Proper techniques for making good solder joints
  • Identifying and fixing common soldering mistakes

Activities:

  • Practice soldering on special boards and kits
  • Soldering basic components (resistors, LEDs)
  • Learning to desolder components
  • Mini-Project: Solder a simple blinking LED circuit onto a board

Topics:

  • Introduction to microcontrollers like Arduino
  • Basic programming (variables, if/else, loops)
  • Controlling lights (LEDs) and reading buttons
  • Using sensors to get information from the world
  • Making lights dim and motors spin with PWM

Activities:

  • Making an LED blink ("Hello World" of electronics)
  • Creating projects that respond to buttons
  • Building simple projects with sensors (e.g., light sensor)
  • Controlling a small motor or dimming an LED
  • Developing a simple interactive project (e.g., traffic light, alarm)

Project 1: Simple Logic Game (5 Days)

  • **Objective:** Build a basic interactive game using logic gates, buttons, and LEDs.
  • **Example:** A "Quiz Buzzer" where the first button pressed lights an LED, or a "Decision Maker" that randomly lights one of two LEDs.
  • **Skills Reinforced:** Logic gate operation, breadboarding, basic input/output.

Project 2: Basic Sensor Interface (5 Days)

  • **Objective:** Connect a simple analog sensor to control a digital output.
  • **Example:** A light-activated LED (using a photoresistor) or a simple temperature indicator (using a thermistor and LEDs).
  • **Skills Reinforced:** Understanding analog input, simple circuit design, basic component integration.

Objectives:

  • Brainstorm and define project scope
  • Research components and circuit designs
  • Develop a detailed project proposal
  • Begin building a breadboard prototype

Objectives:

  • Complete final construction (soldering/enclosure)
  • Thoroughly test and refine the project
  • Prepare and deliver project presentation
  • Submit all project documentation
